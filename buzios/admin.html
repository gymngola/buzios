Como funciona

Inscrições — pedidos do formulário de inscrição. Marque: Novo → Contactado → Inscrito.

Contactos — mensagens da página Contacto (nome, telefone, assunto, mensagem). Marque: Novo → Respondido → Arquivar.

Clientes — base criada automaticamente a partir de inscrições. Actualize membership e faturação.

Imagens — no separador Imagens: arraste ou escolha fotos (várias de uma vez). Atribua a cada slot (hero, ginásio, contacto…). Depois Publicar na loja.

Rascunho / Publicar — planos, imagens e textos: rascunho só neste browser; Publicar actualiza o site para todos.
