Como funciona

Inscrições — pedidos do formulário. Fluxo sugerido: Novo → Contactado → Aguarda docs → Inscrito. Estados são reversíveis (pode voltar atrás). Use «Criar pendente (docs)» para criar o cliente em estado pendente até entregar documentos; «Criar cliente» cria já como activo. Filtros e acções em massa disponíveis.

Contactos — mensagens da página Contacto (nome, telefone, assunto, mensagem). Marque: Novo → Respondido → Arquivar.

Clientes — base a partir de inscrições (botão “Criar cliente” na inscrição) ou manual. Lista densa com prioridade (dívida / a expirar), filtros, ordenação e barra de resumo fixa. Atalhos: / pesquisa, N novo cliente. Seleccione vários para WhatsApp em massa, suspender, arquivar ou exportar. Exportar CSV e copiar telefones usam a selecção se houver. Estados actualizam-se pelas datas. Use “Renovar” ou “Pagar e renovar”. Badge no menu se houver dívidas ou expirados.

Imagens — no separador Imagens: arraste ou escolha fotos (várias de uma vez). Atribua a cada slot (hero, ginásio, contacto…). Depois Publicar no website.

Planos — organizados por ginásio e natação (mensalidades Bebés / Especial / Hidro / 6–99 anos e planos de férias). Edite preços aqui e publique. O formulário de inscrição e as páginas do site usam este catálogo.

Publicar no website — só em Planos, Imagens e Textos. Clientes, inscrições e contactos guardam-se sozinhos (não precisam de publicar).

Segurança / dados

  • Dados operacionais (clientes, inscrições, contactos, newsletter) vivem no Cloudflare D1, não só no Cloudinary.
  • Arquivar ≠ apagar: o registo fica fora da fila diária e pode ser reactivado. Lixeira move para lixo recuperável durante 30 dias; depois o cron faz purge permanente.
  • Apagar já / Apagar definitivamente é irreversível no painel (só recuperação via Time Travel do D1 ou último backup).
  • Recomendado: correr Backup completo (ou aguardar o backup agendado d1_backup) pelo menos a cada poucos dias.
  • Time Travel do D1 recupera a base nos últimos 7 dias (plano Free) / 30 dias (Paid). Os ficheiros datados no Cloudinary (backups/d1-YYYY-MM-DD.json) são a cópia de longa duração.
  • Um hard reload não termina a sessão (a palavra-passe fica no browser). Use Sair ou o botão abaixo para obrigar todos os dispositivos a entrar de novo — útil depois de actualizações do painel.

Dentro de cerca de 1 minuto, todos os painéis abertos pedem login outra vez (incluindo este).
