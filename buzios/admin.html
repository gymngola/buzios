Como funciona

Rascunho — guarda alterações só neste telemóvel/computador. O site público continua igual. Use para pré-visualizar.

Publicar na loja — envia o catálogo para a cloud. Todos os visitantes passam a ver os novos preços, textos e imagens.

Fluxo recomendado

  • Editar planos / imagens / textos
  • Guardar rascunho e abrir o site no mesmo browser para verificar
  • Quando estiver certo → Publicar na loja

Imagens

  • Carregar envia para a Cloudinary (não precisa de URL)
  • “Escolher da média” usa imagens já carregadas
  • Apagar na biblioteca só remove da lista local; o ficheiro na cloud fica (pode apagar no dashboard Cloudinary se quiser)

Se algo falhar
